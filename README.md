## 🐳 How to Run Project Sentinel with Docker

You don't need to have Java, Node.js, or PostgreSQL installed on your machine to run this project. You only need **Docker Desktop**.

### Prerequisites
1. Install [Docker Desktop](https://www.docker.com/products/docker-desktop/) for your operating system.
2. Ensure Docker Desktop is running in the background.

### Quick Start
1. Clone your fork of this repository to your local machine.
2. Open your terminal in the root directory of the project.
3. Run the following command:
   ```bash
   docker compose up --build
